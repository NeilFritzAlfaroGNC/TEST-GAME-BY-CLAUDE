FOOD HEROES DOCUMENTATION
=========================

Project guides are collected in this folder:

- FOOD_HEROES_PROJECT_GUIDE.txt: project structure, systems, dependencies, and testing notes.
- LEVEL1_LAYOUT_GUIDE.txt: gameplay background, character, and conveyor layout maintenance.
- STORY_SCENE_GUIDE.txt: story data, presentation, input, and progression.
- TUTORIAL_IMPLEMENTATION_GUIDE.txt: tutorial overlay and practice-flow notes.
- obsolete_codex_scene_archive.txt: maintenance record for an inactive archived Codex scene.

Third-party notices and licenses remain beside their dependencies where appropriate.
